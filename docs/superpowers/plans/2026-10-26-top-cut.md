# Top Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-elimination top cut after the group stage: organizer publishes a seeded bracket, players report through it, organizer walks over no-shows and finishes the season with a champion (#81).

**Architecture:** A new season status `topcut` sits between `play` and `finished`. Qualifiers get a `seed` and a first-round `slot` on `entries`; the whole bracket derives from those two columns plus the `stage = 'playoff'` match rows (each with a `slot` and an optional `walkover_id`). Pure rules live in `src/lib/league/bracket.ts` (sizes, seeding with rematch avoidance, bracket state, names). `syncBracket` (`src/lib/server/topCut.ts`) is the one writer of playoff rows: after any publish, report, edit or walkover it inserts matches whose two players are known and repoints unreported ones after an edit. Group-stage queries filter `stage = 'group'`, so existing pages are untouched by playoff rows.

**Tech Stack:** SvelteKit · Drizzle (better-sqlite3) · Vitest · Playwright

**Design:** Poroleague Screens canvas, boards `TopCut`, `MobileTopCut`, `AdminTopCut` (https://claude.ai/artifact/JNRggLitUbWrysyA7YTPvE, `project/<Board>.dc.html`).

**Branch:** `plan-15-top-cut`, stacked on `plan-14-more-groups` (#93). PR base `plan-14-more-groups` until #93 merges, then `main`.

## Decisions (grilled 2026-10-26)

1. **Status:** `topcut` between `play` and `finished`. Finalize → `topcut` when `topCutSize > 0`, else `finished`. `topcut` counts as running (blocks opening another season).
2. **Size:** `topCutSize` (per group) is the source of truth; the setup page shows it read-only ("Top N per group → total · byes"). Total = N × groups, 2–32. Every group needs N non-dropped players; dropped players can't qualify and the next one moves up. Bracket = next power of two; empty slots are byes for the top seeds.
3. **Seeding:** seeds by rank then group letter (A1, B1, C1, A2, …), standard bracket order (1 v last). A first-round match between two players of the same group swaps the lower seed with the nearest seed (same rank first) that clears the clash. One group: plain order. First round only.
4. **Level result:** higher seed advances. No game 4, no option.
5. **Unplayed / no-show:** organizer walkover any time (pick who advances, higher seed preselected), audited. No auto-advance.
6. **Timing:** no round dates. Every match shows the moment both players are known. One optional **top cut date** (display only).
7. **Discord:** publish → one pairings post (first round + byes, bracket link, date). Each report → results post labelled "Quarterfinal 2" etc.; walkover → results post "X advances (walkover)"; finish → results post "Champion: X".
8. **Corrections:** a report advances its winner at once. The organizer can change a top-cut result (or walkover) only while the winner's next match is unreported.
9. **Pages:** public `/seasons/[slug]/top-cut` (desktop bracket, phone round chips + match cards); season page panel; admin `Top cut` page (setup, then manage); match pages reused with "Quarterfinal 2" labels.
10. **Afterwards:** archive card "Champion: X"; player/career history adds the top-cut finish (Champion, Runner-up, Semifinal, Quarterfinal, Round of 16…); season page champion card. No placings table.

**Deviations found while planning (call out in the PR):**

- **No drop in the top cut.** A drop voids all of a player's matches, which would rewrite the group standings the bracket was seeded from. In `topcut` the Drop button stays hidden (it already only shows in `play`); a withdrawal is a walkover.
- **Champion post at Finish, not at the final's report**, so a flagged final is settled before Discord announces it. The organizer clicks **Finish season** once the final has a winner and no top-cut flag is open (same pattern as Finalize).
- **No `Top cut` nav tab**: the boards keep the tab bar at Season / Schedule / Legends / Archive and link the bracket from the season page.
- Reports and edits of playoff matches **don't clear group tiebreaks** (today every report clears them).

```ts
export const MAX_CUT = 32;

export const bracketSize = (n: number) => 2 ** Math.ceil(Math.log2(Math.max(2, n)));

// Standard order: first-round pair i holds order[2i] and order[2i + 1]. 1 meets the last seed, and
// 1 and 2 can only meet in the final.
export function seedOrder(size: number): number[] {
	let order = [1, 2];
	while (order.length < size) {
		const n = order.length * 2;
		order = order.flatMap((s) => [s, n + 1 - s]);
	}
	return order;
}

// `groups` holds each group's qualifiers best first, all the same length. Seeds go A1, B1, C1, A2…
// Returns the first round as slots (pair i = slots 2i, 2i + 1; null = bye). Two players of one group
// never meet in the first round: the lower seed swaps with the nearest seed that clears the clash.
export function drawBracket(groups: string[][]): (string | null)[] {
	const seeds = groups[0].flatMap((_, r) => groups.map((g) => g[r]));
	const seedNo = new Map(seeds.map((id, i) => [id, i]));
	const group = new Map(groups.flatMap((g, i) => g.map((id) => [id, i] as const)));
	const tier = (id: string) => Math.floor(seedNo.get(id)! / groups.length);
	const slots = seedOrder(bracketSize(seeds.length)).map((s) => seeds[s - 1] ?? null);
	if (groups.length < 2) return slots;

	const mate = (i: number) => i ^ 1;
	const paired = (i: number) => slots[i] !== null && slots[mate(i)] !== null;
	const clash = (i: number) => paired(i) && group.get(slots[i]!) === group.get(slots[mate(i)]!);
	const swap = (i: number, j: number) => ([slots[i], slots[j]] = [slots[j], slots[i]]);
	for (let i = 0; i < slots.length; i += 2) {
		if (!clash(i)) continue;
		const low = seedNo.get(slots[i]!)! > seedNo.get(slots[i + 1]!)! ? i : i + 1;
		const id = slots[low]!;
		// ponytail: O(n²) over at most 32 slots.
		const j = slots
			.map((_, j) => j)
			.filter((j) => j !== low && j !== mate(low) && paired(j))
			.sort(
				(a, b) =>
					Math.abs(tier(slots[a]!) - tier(id)) - Math.abs(tier(slots[b]!) - tier(id)) ||
					Math.abs(seedNo.get(slots[a]!)! - seedNo.get(id)!) -
						Math.abs(seedNo.get(slots[b]!)! - seedNo.get(id)!)
			)
			.find((j) => {
				swap(low, j);
				const ok = !clash(low) && !clash(j);
				swap(low, j);
				return ok;
			});
		if (j === undefined) throw new Error('No first round without a group rematch');
		swap(low, j);
	}
	return slots;
}
```

```ts
export type CutMatch = {
	round: number;
	slot: number | null;
	p1Id: string;
	p2Id: string;
	p1Games: number | null;
	p2Games: number | null;
	reportedBy: string | null;
	walkoverId: string | null;
};

// A level result sends the higher seed (lower number) through.
export function winnerOf(m: CutMatch, seedOf: (id: string) => number): string | null {
	if (m.walkoverId) return m.walkoverId;
	if (!m.reportedBy) return null;
	if (m.p1Games! !== m.p2Games!) return m.p1Games! > m.p2Games! ? m.p1Id : m.p2Id;
	return seedOf(m.p1Id) < seedOf(m.p2Id) ? m.p1Id : m.p2Id;
}

export type Slot<M extends CutMatch> = {
	round: number;
	slot: number;
	p1: string | null;
	p2: string | null;
	bye: boolean;
	match: M | null;
	winner: string | null;
};

// The whole bracket from the first-round layout and the playoff rows. A row only counts while it
// still holds the slot's players (an edit upstream repoints it; see syncBracket).
export function bracket<M extends CutMatch>(
	layout: (string | null)[],
	ms: M[],
	seedOf: (id: string) => number
): Slot<M>[][] {
	const rounds: Slot<M>[][] = [];
	let entrants = layout;
	for (let round = 1; entrants.length > 1; round++) {
		const slots = Array.from({ length: entrants.length / 2 }, (_, slot): Slot<M> => {
			const [p1, p2] = [entrants[2 * slot], entrants[2 * slot + 1]];
			// Only the first round has byes; later an empty side means that match isn't decided yet.
			const bye = round === 1 && (p1 === null) !== (p2 === null);
			const row = ms.find((m) => m.round === round && m.slot === slot) ?? null;
			const match = row && row.p1Id === p1 && row.p2Id === p2 ? row : null;
			const winner = bye ? (p1 ?? p2) : match ? winnerOf(match, seedOf) : null;
			return { round, slot, p1, p2, bye, match, winner };
		});
		rounds.push(slots);
		entrants = slots.map((s) => s.winner);
	}
	return rounds;
}

const left = (round: number, rounds: number) => 2 ** (rounds - round + 1);

export function roundName(round: number, rounds: number) {
	const n = left(round, rounds);
	return n === 2 ? 'Final' : n === 4 ? 'Semifinals' : n === 8 ? 'Quarterfinals' : `Round of ${n}`;
}

export function matchName(round: number, slot: number, rounds: number) {
	const n = left(round, rounds);
	if (n === 2) return 'Final';
	if (n === 4 || n === 8) return `${n === 4 ? 'Semifinal' : 'Quarterfinal'} ${slot + 1}`;
	return `Round of ${n} · ${slot + 1}`;
}

// "A1" = 1st in Group A. Seeds run A1, B1, …, A2, B2, … so the place is the seed's tier.
export const seedLabel = (seed: number, groups: number) =>
	`${String.fromCharCode(65 + ((seed - 1) % groups))}${Math.ceil(seed / groups)}`;

// How far a player got: Champion, Runner-up, or the round they went out in; null outside the cut.
export function cutFinish(rounds: Slot<CutMatch>[][], playerId: string): string | null {
	const mine = rounds.flat().filter((s) => s.p1 === playerId || s.p2 === playerId);
	if (!mine.length) return null;
	const last = mine[mine.length - 1];
	if (last.winner === playerId) return last.round === rounds.length ? 'Champion' : null;
	if (last.round === rounds.length) return last.winner ? 'Runner-up' : null;
	if (!last.winner) return null;
	const n = left(last.round, rounds.length);
	return n === 4 ? 'Semifinal' : n === 8 ? 'Quarterfinal' : `Round of ${n}`;
}
```

```ts
import { and, eq, isNotNull } from 'drizzle-orm';
import {
	bracket,
	bracketSize,
	drawBracket,
	MAX_CUT,
	seedLabel,
	type Slot
} from '#lib/league/bracket.ts';
import { groupName } from '#lib/season.ts';
import { db } from '#lib/server/db/index.ts';
import { audit, entries, matches, seasons } from '#lib/server/db/schema.ts';
import type { Match, Tx } from '#lib/server/matches.ts';
import { groupStandings, seasonEntries, type Season } from '#lib/server/seasons.ts';

type Db = typeof db | Tx;

// Each group's top N by the final standings (tiebreaks settled at finalize), dropped players skipped.
function qualifiers(season: Season) {
	const list = seasonEntries(season.id);
	const out = new Set(list.filter((e) => e.dropped).map((e) => e.playerId));
	const per = season.topCutSize ?? 0;
	const groups = groupStandings(season, list).map((g) =>
		g.rows.filter((r) => !out.has(r.playerId)).slice(0, per)
	);
	return { per, groups, list };
}

export function cutPreview(season: Season) {
	const { per, groups, list } = qualifiers(season);
	const total = per * groups.length;
	const short = groups.findIndex((g) => g.length < per);
	const problem =
		total < 2
			? 'The top cut needs at least 2 players. Set the top cut per group on Season.'
			: total > MAX_CUT
				? `${total} players is more than the ${MAX_CUT} a bracket takes. Lower the top cut per group on Season.`
				: short >= 0
					? `${groupName(short + 1)} has only ${groups[short].length} players who can qualify.`
					: null;
	const size = { per, total, bracket: bracketSize(total), byes: bracketSize(total) - total };
	if (problem) return { problem, size, firstRound: [] };
	const slots = drawBracket(groups.map((g) => g.map((r) => r.playerId)));
	const seedOf = new Map(
		groups[0].flatMap((_, r) =>
			groups.map((g, i) => [g[r].playerId, r * groups.length + i + 1] as const)
		)
	);
	const name = (id: string | null) => {
		if (!id) return null;
		const e = list.find((x) => x.playerId === id)!;
		return { id, name: e.displayName, label: seedLabel(seedOf.get(id)!, groups.length) };
	};
	return {
		problem,
		size,
		slots,
		seedOf,
		firstRound: Array.from({ length: slots.length / 2 }, (_, i) => ({
			p1: name(slots[2 * i]),
			p2: name(slots[2 * i + 1])
		}))
	};
}

// The published bracket: layout from entries.slot, seeds from entries.seed.
function cutEntries(tx: Db, seasonId: number) {
	const rows = tx
		.select({ playerId: entries.playerId, seed: entries.seed, slot: entries.slot })
		.from(entries)
		.where(and(eq(entries.seasonId, seasonId), isNotNull(entries.slot)))
		.all();
	const layout: (string | null)[] = Array(rows.length ? bracketSize(rows.length) : 0).fill(null);
	for (const r of rows) layout[r.slot!] = r.playerId;
	const seeds = new Map(rows.map((r) => [r.playerId, r.seed!]));
	return { layout, seedOf: (id: string) => seeds.get(id) ?? Infinity, seeds };
}

const cutRows = (tx: Db, seasonId: number) =>
	tx
		.select()
		.from(matches)
		.where(and(eq(matches.seasonId, seasonId), eq(matches.stage, 'playoff')))
		.all();

export const cutRounds = (seasonId: number) => {
	const n = cutEntries(db, seasonId).layout.length;
	return n ? Math.log2(n) : 0;
};

export function cutState(season: Season, tx: Db = db) {
	const { layout, seedOf, seeds } = cutEntries(tx, season.id);
	const rounds: Slot<Match>[][] = layout.length
		? bracket(layout, cutRows(tx, season.id), seedOf)
		: [];
	const groupCount = new Set(
		seasonEntries(season.id)
			.map((e) => e.group)
			.filter(Boolean)
	).size;
	const final = rounds.at(-1)?.[0];
	return {
		published: layout.length > 0,
		rounds,
		seeds,
		label: (id: string) => seedLabel(seeds.get(id)!, groupCount),
		champion: final?.winner ?? null
	};
}

// The one writer of playoff rows: inserts a match once both players are known, and repoints an
// unreported match after an upstream edit. ponytail: re-reads after each fix; at most 31 matches.
export function syncBracket(tx: Tx, season: Season) {
	for (;;) {
		const { layout, seedOf } = cutEntries(tx, season.id);
		if (!layout.length) return;
		const rows = cutRows(tx, season.id);
		const stale = bracket(layout, rows, seedOf)
			.flat()
			.find((s) => !s.bye && s.p1 && s.p2 && !s.match);
		if (!stale) return;
		const row = rows.find((m) => m.round === stale.round && m.slot === stale.slot);
		if (row)
			tx.update(matches)
				.set({ p1Id: stale.p1!, p2Id: stale.p2! })
				.where(eq(matches.id, row.id))
				.run();
		else
			tx.insert(matches)
				.values({
					seasonId: season.id,
					stage: 'playoff',
					round: stale.round,
					slot: stale.slot,
					p1Id: stale.p1!,
					p2Id: stale.p2!
				})
				.run();
	}
}

export function publishCut(season: Season, date: string | null, actorId: string) {
	const p = cutPreview(season);
	if (p.problem || !p.slots) throw new Error(p.problem ?? 'Nothing to publish');
	db.transaction((tx) => {
		if (cutEntries(tx, season.id).layout.length)
			throw new Error('The top cut is already published');
		p.slots!.forEach((playerId, slot) => {
			if (playerId)
				tx.update(entries)
					.set({ seed: p.seedOf!.get(playerId)!, slot })
					.where(and(eq(entries.seasonId, season.id), eq(entries.playerId, playerId)))
					.run();
		});
		tx.update(seasons).set({ topCutDate: date }).where(eq(seasons.id, season.id)).run();
		tx.insert(audit)
			.values({
				seasonId: season.id,
				actorId,
				action: 'topcut',
				after: { size: p.size.total, date }
			})
			.run();
		syncBracket(tx, season);
	});
}
```

```ts
async function inCut(event: RequestEvent) {
	const user = await organizerAction(event);
	const form = await event.request.formData();
	const season = getSeason(event.params.slug, user);
	return { user, form, season: season.status === 'topcut' ? season : null };

export const actions: Actions = {
	edit: editResult,
	keep: keepFlag,

	publish: async (event) => {
		const { user, form, season } = await inCut(event);
		if (!season) return fail(409, { message: 'The season is not in its top cut.' });
		if (cutState(season).published)
			return fail(409, { message: 'The top cut is already published.' });
		const date = String(form.get('date') ?? '');
		if (date && !DATE.test(date)) return fail(400, { message: 'Pick a date, or leave it empty.' });
		const preview = cutPreview(season);
		if (preview.problem) return fail(400, { message: preview.problem });
		publishCut(season, date || null, user.id);
		const s = cutState(season);
		const rounds = cutRounds(season.id);
		const discord = pairingsEnabled();
		if (discord) {
			const pairs = s.rounds[0]
				.filter((x) => x.match)
				.map((x) => ({ group: null, p1Id: x.p1!, p2Id: x.p2! }));
			const body = pairingsPost(
				`${season.name} · Top cut${date ? ` · ${date}` : ''}`,
				`${event.url.origin}/seasons/${season.slug}/top-cut`,
				[{ round: 1, name: roundName(1, rounds), pairs }],
				discordMentions(pairs.flatMap((p) => [p.p1Id, p.p2Id]))
			);
			const byes = s.rounds[0]
				.filter((x) => x.bye)
				.map((x) => seasonEntries(season.id).find((e) => e.playerId === x.winner)!.displayName);
			if (byes.length) body.content += `\nByes: ${byes.join(', ')}`;
			postPairings(body);
		}
		return { message: `Top cut published${discord ? ' and posted in Discord' : ''}.` };
	},

	walkover: async (event) => {
		const { user, form, season } = await inCut(event);
		if (!season) return fail(409, { message: 'The season is not in its top cut.' });
		const match = getMatch(season.id, Number(form.get('matchId')));
		const winnerId = String(form.get('winnerId'));
		if (!match || match.stage !== 'playoff') error(404, 'Match not found');
		if (match.reportedBy || match.walkoverId)
			return fail(409, { message: 'This match already has a result.' });
		if (winnerId !== match.p1Id && winnerId !== match.p2Id)
			return fail(400, { message: 'Pick one of the two players.' });
		walkover(season, match, winnerId, user.id);
		const name = seasonEntries(season.id).find((e) => e.playerId === winnerId)!.displayName;
		postResult(
			walkoverEmbed(
				`${season.name} · Top cut · ${matchName(match.round, match.slot ?? 0, cutRounds(season.id))}`,
				name,
				`${event.url.origin}/seasons/${season.slug}/matches/${match.id}`
			)
		);
		return { message: `${name} advances.` };
	},

	finish: async (event) => {
		const { user, season } = await inCut(event);
		if (!season) return fail(409, { message: 'The season is not in its top cut.' });
		const s = cutState(season);
		if (!s.champion) return fail(409, { message: 'The final has no result yet.' });
		if (s.rounds.flat().some((x) => x.match?.flaggedBy && !x.match.flagResolvedAt))
			return fail(409, { message: 'Resolve the flagged top-cut results first.' });

			championEmbed(season.name, name, `${event.url.origin}/seasons/${season.slug}/top-cut`)
		);
		return { message: `${season.name} is finished. ${name} is the champion.` };
	}
};
```
