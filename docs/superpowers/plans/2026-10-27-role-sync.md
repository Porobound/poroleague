# Player Role Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Signups, withdrawals, removals, drops and season end add or remove the global Discord player role.

**Architecture:** `setPlayerRole(discordIds, on)` in `src/lib/server/discord.ts` makes one bot-token REST call per member, sequentially, retrying a 429 up to twice; failures are logged, never thrown. `playerRole(on, playerIds)` in `seasons.ts` maps player ids to Discord ids and fires it without awaiting. Server functions call it after their DB write, so routes need no change. Both env vars are optional (unset = off), so existing `.env` files keep working.

**Tech Stack:** SvelteKit `defineEnvVars`, Drizzle, Vitest.

Spec: `docs/spec.md` → Discord integration → Player role sync. Issue #8.

```ts
// One call per member, in order, so a season's worth of removals stays under the rate limit.
// Fire-and-forget: failures are logged and never block the league change behind them.
export async function setPlayerRole(discordIds: string[], on: boolean) {
	if (!DISCORD_BOT_TOKEN || !PLAYER_ROLE_ID) return;
	for (const id of discordIds) {
		for (let attempt = 0; attempt < 3; attempt++) {
			try {
				const res = await fetch(`${API}/guilds/${GUILD_ID}/members/${id}/roles/${PLAYER_ROLE_ID}`, {
					method: on ? 'PUT' : 'DELETE',
					headers: { authorization: `Bot ${DISCORD_BOT_TOKEN}` }
				});
				if (res.status === 429) {
					const { retry_after } = (await res.json()) as { retry_after: number };
					await new Promise((r) => setTimeout(r, retry_after * 1000));
					continue;
				}
				if (!res.ok) console.error(`Discord role sync failed: ${res.status} ${await res.text()}`);
			} catch (e) {
				console.error(e);
			}
			break;
		}
	}
}
```

```ts
// Discord player role follows signups (spec: Player role sync). Fire-and-forget, like the webhooks.
export function playerRole(on: boolean, playerIds: string[]) {
	if (!playerIds.length) return;
	const ids = db
		.select({ discordId: players.discordId })
		.from(players)
		.where(and(inArray(players.id, playerIds), isNotNull(players.discordId)))
		.all()
		.map((p) => p.discordId!);
	if (ids.length) void setPlayerRole(ids, on);
}

export const endPlayerRoles = (seasonId: number) =>
	playerRole(
		false,
		db.select({ id: entries.playerId }).from(entries).where(eq(entries.seasonId, seasonId)).all().map((e) => e.id)
	);
```
